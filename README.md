ElimuCloud ☁️ — Localized Azure AZ-900 AI Study Buddy

Simplifying Microsoft Azure AZ-900 concepts for African developers using relatable, localized analogies.

📌 Problem Statement

Preparing for cloud certifications like Microsoft Azure Fundamentals (AZ-900) often presents friction for beginners:

Abstract Concepts: Terminology like CapEx vs. OpEx, Fault Tolerance, and Availability Zones can feel dry and overwhelming.

Western-Centric Examples: Standard documentation often uses corporate setups that do not resonate with local, real-world experiences across Africa.

Passive Learning: Practicing multiple-choice questions without immediate, contextual feedback leaves learners unsure of why an answer is correct.

💡 The Solution

ElimuCloud bridges the gap between complex cloud architecture and accessible tech education. It serves as an interactive AI study companion that translates abstract Azure concepts into familiar everyday experiences—such as matatus, M-Pesa, open-air markets, and regional power grids.

✨ Key Features

Localized AI Chat Tutor: Get instant explanations grounded in relatable cultural analogies.

Domain Quick Filters: Effortlessly navigate core AZ-900 objective domains:

Cloud Concepts

Azure Architecture & Services

Management & Governance

High-Yield Exam Tips: Highlight common traps and tricky exam patterns to boost test preparedness.

Swahili/Sheng Toggle Support: Switch between standard English and local phrasing for maximum engagement.

🛠️ Tech Stack

Frontend: React / Vite / HTML5 / Tailwind CSS

AI Model/API: Custom Prompt Engine / OpenAI API / Gemini API

Rapid Prototyping: Bolt.new / Lovable

Deployment: Netlify / Vercel

🚀 Getting Started

Follow these instructions to set up and run the project locally.

Prerequisites

Node.js (v18.0 or higher)

npm or yarn installed

Installation

Clone the repository:

git clone https://github.com/your-username/elimucloud-az900-buddy.git
cd elimucloud-az900-buddy


Install dependencies:

npm install


Configure Environment Variables:
Create a .env file in the root directory and add your API keys:

VITE_AI_API_KEY=your_api_key_here


Run the development server:

npm run dev


Open http://localhost:5173 in your browser to view the app.
